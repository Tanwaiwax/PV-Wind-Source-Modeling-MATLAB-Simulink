# MATLAB Scripts

This folder contains the MATLAB scripts used to reproduce the numerical analyses and figures reported in the manuscript:

**Integrated Solar Photovoltaic and Wind-Energy Source Modeling Using MATLAB/Simulink**

The scripts include:

- Rayleigh wind-speed statistical modeling
- NSRDB-derived plane-of-array irradiance comparison
- PV series-string mismatch analysis
- 24-hour PV–wind source-profile simulation
- Figure-generation and verification calculations
